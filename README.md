# Gaz-Olcum-Modulu
Boşluklar dahil tam **226 karakter** uzunluğundaki yeni özet:  > ESP32 ve C++ tabanlı gerçek zamanlı gaz izleme projesi. MQ-4 (CH4), MQ-5 (LPG) ve MQ-7 (CO) sensörlerinden alınan anlık veriler, PCF8574 I2C 16x2 LCD ekranda aşağıdan yukarı kayan özel bir UI algoritmasıyla görüntülenir.
